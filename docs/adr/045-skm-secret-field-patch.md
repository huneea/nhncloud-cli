# ADR-045: SKM 기밀 데이터의 필드 하나만 바꾸는 patch 는 미리보기가 기본이고 반영 뒤 다시 조회해 대조한다

- **status**: `accepted`
- **결정**: 값이 JSON 객체인 기밀 데이터에서 최상위 필드 하나를 더하거나 바꾸거나 지우는 `skm secret patch <key-id> <field>` 와, 필드 하나를 읽는 `skm secret get <key-id> --field <name>` 을 둔다.
  - `patch` 는 기본이 미리보기다. 현재 값을 읽어 동작(`added`, `replaced`, `deleted`, `unchanged`)만 정하고 쓰지 않는다. `--yes` 를 줄 때만 전체 값을 `PUT` 한다. 동작이 `unchanged` 면 `--yes` 를 줘도 쓰지 않는다.
  - 이미 있는 필드의 값을 다른 값으로 바꾸려면 `--replace` 가 있어야 한다. 없으면 미리보기에서도 종료 코드 3으로 거절한다. 값이 같으면 `--replace` 없이 `unchanged` 다.
  - 새 값은 `--file` 이나 표준 입력으로만 받고 JSON 문자열로 넣는다. `--value` 는 두지 않는다. 받은 바이트를 그대로 쓰고 끝 줄바꿈을 지우지 않으며, 줄바꿈으로 끝나면 stderr 에 경고만 낸다([[adr-039]]).
  - 반영 뒤 같은 키를 다시 조회해, 바꾼 필드 값의 SHA-256 이 입력과 같은지(지웠으면 없는지)와 다른 필드가 반영 전과 같은지 대조한다. 어긋나거나 다시 조회하지 못하면 결과를 출력한 뒤 종료 코드 1로 끝난다.
  - 값과 해시는 어떤 출력에도 내지 않는다. 출력은 키 ID, 필드 이름, 동작, 반영 여부, 두 대조 결과뿐이다. `PUT` 응답에 실린 전체 값도 버린다([[adr-040]]).
  - 현재 값이 JSON 객체가 아니거나, 다시 쓰면 값이 바뀌는 숫자(안전 정수 범위 밖의 정수, 유효 숫자 15자리를 넘는 소수)가 있으면 종료 코드 3으로 거절한다.
  - 다시 쓸 때 들여쓰기와 끝 줄바꿈은 원래 값을 따르고, 그 밖의 공백과 이스케이프는 `JSON.stringify` 형식으로 바뀐다. 필드 순서는 유지하고 새 필드는 끝에 붙는다.
- **맥락**:
  - 기밀 데이터 하나에 설정 여러 개를 JSON 객체로 담아 두고 키 하나만 바꾸는 사용이 많다. 기존 `secret update` 는 전체 값을 바꾸므로 사용자가 조회, 병합, 갱신, 대조 스크립트를 따로 들고 있었다.
  - 기밀 데이터에는 버전이 없다. 공식 문서의 키 버전은 대칭키·비대칭키에만 있고, 수정 API(2026-03-10 추가)는 값을 덮어쓴다. 잘못 덮어쓴 값은 되돌릴 수 없다.
  - API 는 필드 단위 수정과 조건부 쓰기(버전, ETag)를 제공하지 않는다. CLI 가 읽고 합쳐 쓰는 방법뿐이다.
  - 승인 기능을 켠 키 저장소에서 API 수정이 어떻게 처리되는지 공식 문서에 없다. 성공 응답을 받아도 값이 바뀌었다고 단정할 수 없다.
  - `JSON.parse` 는 2^53 을 넘는 정수와 긴 소수를 반올림하고 같은 키가 둘이면 뒤의 값만 남긴다. 다른 필드를 그대로 다시 써도 값이 바뀐다.
  - V8 의 `JSON.parse` 오류 문구는 입력 일부를 담는다. 오류에 그 문구를 실으면 비밀값이 stderr 에 나간다.
- **대안 기각**:
  - `--yes` 없으면 종료 코드 3([[adr-040]] 의 삭제 명령 방식): 무엇이 바뀔지 보려면 쓰기 명령을 실패시켜야 한다. 미리보기가 같은 판정을 하면서 쓰지 않는 쪽이 자동화에서 다루기 쉽다.
  - `--value` 지원: 프로세스 목록과 셸 이력에 남는다. 필드 단위 수정은 반복 실행이 많아 노출이 쌓인다.
  - 값을 JSON 으로 해석하는 옵션(`--json-value`): 필드 값은 대부분 비밀번호와 토큰 문자열이다. 필요가 확인되면 더한다.
  - 점 표기 경로(`a.b.c`)로 중첩 필드 수정: 필드 이름에 점이 들어간 경우와 구분할 규칙이 필요하다. 최상위 필드로 요구를 채운다.
  - 반영 전 값을 로컬에 백업: 비밀값을 파일에 쓰지 않는다는 캐시 규칙과 충돌한다.
  - 대조 결과에 해시 출력: 짧은 비밀번호는 SHA-256 으로 대입 공격이 가능하다.
- **결과**:
  - 얻는 것: 필드 하나를 바꾸는 일이 명령 하나로 끝나고, 미리보기와 대조로 덮어쓰기 실수와 승인 대기 같은 반영 실패를 종료 코드로 알 수 있다. 같은 값으로 다시 실행하면 `unchanged` 라 결과를 모르는 실패 뒤에도 재실행이 안전하다.
  - 감당할 것: 읽은 뒤 쓰기 전에 다른 쓰기가 들어오면 그 변경을 덮어쓴다. 대조가 이 경우를 잡아 종료 코드 1을 내지만 덮어쓴 값은 되돌리지 못한다. 중복 키가 있는 값은 뒤의 키만 남긴다. 필드 값은 문자열로만 쓸 수 있다. 기밀 데이터 크기 상한(공식 문서 32KB 텍스트)은 서버가 판정한다.
- **적용 범위**: `skm secret patch` 와 `skm secret get --field`. `secret update` 와 다른 SKM 명령의 입력·출력 규칙은 바꾸지 않는다.
